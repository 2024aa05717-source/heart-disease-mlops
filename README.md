# Heart Disease Prediction – MLOps Project

## Objective
Build an end-to-end MLOps pipeline to predict heart disease using the UCI Heart Disease dataset.

## Features
- Data preprocessing & EDA
- Model training with Scikit-learn
- Experiment tracking using MLflow
- CI/CD using GitHub Actions
- Model serving with FastAPI
- Docker & Kubernetes deployment
- Monitoring & logging

## Tech Stack
Python, Scikit-learn, MLflow, FastAPI, Docker, Kubernetes, GitHub Actions
